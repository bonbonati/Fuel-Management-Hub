# PetroFleet Sudan · بترو

نموذج تفاعلي (Prototype) لمنصة إدارة الوقود في السودان، يربط بين:

- **تطبيق السائق**: تصريح وقود برمز QR متجدد، فحص العدّاد قبل التعبئة، سجل الإيصالات، وتقديم طلبات زيادة الحد أو إعادة التفعيل.
- **تطبيق مدير الأسطول**: الرصيد المسبق، ميزانيات الفئات المرتبطة بالسائقين، اعتماد الطلبات، قواعد الوقود ومكافحة الاحتيال.
- **تطبيق عامل المحطة**: التعرّف على المركبة عبر QR أو RFID، تحديد المسدس والكمية، وملخص الوردية.
- **لوحة تحكم الويب**: لإدارة الأسطول والمحطة مع تعديل جميع البيانات، تفعيل/إيقاف السائقين، وإعدادات ضريبة القيمة المضافة.

الواجهة ثنائية اللغة (العربية افتراضياً، والإنجليزية) وبالجنيه السوداني (ج.س / SDG).

> جميع البيانات تجريبية لأغراض العرض فقط، ولا يوجد خادم أو قاعدة بيانات خلف النموذج.

## التشغيل

افتح `index.html` في أي متصفح، أو استخدم رابط GitHub Pages الخاص بالمستودع.

## التقنيات

HTML وCSS وJavaScript في ملف واحد، مع أيقونات [Lucide](https://lucide.dev) وخطوط Google Fonts.
